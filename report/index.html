Proof

A report you can check

The handover is not a decorated tree. It is a file in which a stranger could see what was read, what was concluded, and what is still unknown.

One public file

The example linked below is a redacted file from the Polesie / Charužka work that this practice grew out of. It is public so you can see the format: places on a map, events in time, a few stories, and a source list with labels.

Those pages are not a catalogue of results we undertake to repeat. How far any new line goes depends on which books survived and whether the place-name in the family story can be tied to a parish. The file shows how we mark that limit. It does not show a limit we will reach for you.

Labels

Every claim is one of three things. Mixing them into a single “family story” is how errors become tradition.

  • Record — a cited document says it.
  • Inference — we concluded it, and the steps are written down.
  • Open — not established. DNA, when it is used, is marked as DNA.
How a row is marked

The log

What was looked for, what was found, and what is missing from the fonds. A negative search stays in the file so the next person does not repeat it in the dark.

The sample log is inside the public file, beside the map and the stories.
