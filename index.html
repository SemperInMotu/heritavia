Start with one line, or with a wider question. We reply with an assessment — what is realistic, and what the work would cost — before any research is agreed.

How an enquiry moves

From a brief to a report

1. You write what you know

Names, a place as the family says it, a rough period, and whatever papers you already have.

2. We assess the question

Which archives are even relevant, what is already in hand, and what a first stage can and cannot settle.

3. Research, if you want it

Work in the repositories that hold the line. A negative search is written down; it is part of the result.

4. A report that separates claims

Record, inference, and open question stay labelled. You can see the ceiling, not a filled-in tree.
